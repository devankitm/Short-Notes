SQL Short Notes

Quick revision notes for relational databases, MySQL commands and everyday SQL queries.

1. What is SQL?

SQL (Structured Query Language) is used to create, read, update and delete data in relational databases such as MySQL.

Remember: SQL works with structured data stored in tables.

2. Create Database

Use CREATE DATABASE to create a new database and USE to select it.

SQL
CREATE DATABASE college;
USE college;

3. Create Table

A table stores data in rows and columns. Define a primary key when a column uniquely identifies each row.

SQL
CREATE TABLE students (
  id INT PRIMARY KEY,
  name VARCHAR(50),
  age INT
);

4. SELECT

SELECT retrieves data from a table. Use WHERE when you need filtering.

SQL
SELECT name, age
FROM students
WHERE age >= 18;

5. INSERT

INSERT INTO adds new rows.

SQL
INSERT INTO students (id, name, age)
VALUES (1, 'Ankit', 21);

6. UPDATE

Use UPDATE to change existing rows. Always use a suitable WHERE condition.

SQL
UPDATE students
SET age = 22
WHERE id = 1;

7. DELETE

DELETE removes rows. Without WHERE, all rows may be removed.

SQL
DELETE FROM students
WHERE id = 1;

8. JOIN

JOIN combines related rows from multiple tables.

SQL
SELECT students.name, courses.course_name
FROM students
INNER JOIN courses
ON students.id = courses.student_id;
