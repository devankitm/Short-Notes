SQL Complete Notes

SQL ko zero se advanced level tak simple language me samjho. Is page me concepts, syntax, examples, practical queries, interview points aur common mistakes included hain.

1. What is SQL?

SQL ka full form Structured Query Language hai. SQL ka use relational database me stored data ko create, read, update aur delete karne ke liye hota hai.

Simple words me: SQL ek language hai jiske through hum database ko instructions dete hain.

Example: Agar college database me 10,000 students hain aur hume sirf CSE students chahiye, to SQL query se hum required data filter kar sakte hain.

SQL ka use kaha hota hai?

  • Web applications
  • Banking systems
  • College management systems
  • E-commerce websites
  • Employee management systems
  • Inventory management systems
  • Government and enterprise applications

2. What is a Database?

Database ek organized collection of data hota hai. Data ko structured way me store kiya jata hai taaki use easily search, update aur manage kiya ja sake.

Real-life example

College ke paas students ka data ho sakta hai:

  • Student ID
  • Name
  • Course
  • Age
  • Marks

Ye information database ke andar tables me store ki ja sakti hai.

3. DBMS vs RDBMS

DBMS database ko manage karne ka system hai. RDBMS data ko related tables ke form me organize karta hai.

  • DBMS: basic database management.
  • RDBMS: tables, relationships, keys and constraints.
  • MySQL, PostgreSQL, Oracle and SQL Server are popular RDBMS examples.
Remember: SQL language hai; MySQL ek RDBMS/software hai jo SQL commands ko execute karta hai.

4. Types of SQL Commands

SQL commands ko commonly in categories me divide kiya jata hai:

  • DDL: Data Definition Language
  • DML: Data Manipulation Language
  • DQL: Data Query Language
  • DCL: Data Control Language
  • TCL: Transaction Control Language

Important commands

DDL: CREATE, ALTER, DROP, TRUNCATE
DML: INSERT, UPDATE, DELETE
DQL: SELECT
DCL: GRANT, REVOKE
TCL: COMMIT, ROLLBACK, SAVEPOINT

5. CREATE DATABASE

New database create karne ke liye CREATE DATABASE command use hoti hai.

SQL 
CREATE DATABASE college;

Database select karna

SQL 
USE college;

Existing databases dekhna

SQL 
SHOW DATABASES;

6. DROP DATABASE

DROP DATABASE poori database ko delete kar deta hai. Isliye production environment me carefully use karna chahiye.

SQL 
DROP DATABASE college;

7. CREATE TABLE

Table database ke andar data ko rows aur columns ke form me store karti hai.

SQL 
CREATE TABLE students (
  id INT PRIMARY KEY,
  name VARCHAR(50),
  age INT,
  course VARCHAR(50)
);

Table dekhna

SQL 
SHOW TABLES;

Table structure dekhna

SQL 
DESCRIBE students;

8. SQL Data Types

Data type define karta hai ki kisi column me kis type ka data store hoga.

  • INT: whole numbers
  • DECIMAL: exact decimal values
  • VARCHAR: variable-length text
  • CHAR: fixed-length text
  • DATE: date
  • DATETIME: date + time
  • BOOLEAN: true/false style values
  • TEXT: larger text data
SQL 
CREATE TABLE employees (
  id INT,
  name VARCHAR(100),
  salary DECIMAL(10,2),
  joining_date DATE,
  active BOOLEAN
);

9. INSERT INTO

Table me new record add karne ke liye INSERT INTO use hota hai.

SQL 
INSERT INTO students (id, name, age, course)
VALUES (1, 'Ankit', 21, 'CSE');

Multiple rows insert karna

SQL 
INSERT INTO students (id, name, age, course)
VALUES
  (2, 'Rahul', 22, 'CSE'),
  (3, 'Amit', 20, 'ECE'),
  (4, 'Priya', 21, 'CSE');

10. SELECT

Database se data read/retrieve karne ke liye SELECT command use hoti hai.

SQL 
SELECT * FROM students;

Sirf required columns bhi select kar sakte hain.

SQL 
SELECT name, course
FROM students;

11. WHERE Clause

WHERE rows ko condition ke basis par filter karta hai.

SQL 
SELECT *
FROM students
WHERE age >= 21;

Common comparison operators

  • = equal
  • > greater than
  • < less than
  • >= greater than or equal
  • <= less than or equal
  • <> / != not equal

12. AND, OR and NOT

Multiple conditions combine karne ke liye logical operators use hote hain.

SQL 
SELECT *
FROM students
WHERE age >= 20
  AND course = 'CSE';
SQL 
SELECT *
FROM students
WHERE course = 'CSE'
   OR course = 'ECE';

13. DISTINCT

Duplicate values ko remove karke unique values dekhne ke liye DISTINCT use hota hai.

SQL 
SELECT DISTINCT course
FROM students;

14. ORDER BY

Data ko ascending ya descending order me sort karne ke liye ORDER BY use hota hai.

SQL 
SELECT *
FROM students
ORDER BY age ASC;
SQL 
SELECT *
FROM students
ORDER BY age DESC;

15. LIMIT

Result me limited number of rows chahiye to LIMIT use karte hain.

SQL 
SELECT *
FROM students
LIMIT 5;

16. UPDATE

Existing record ko modify karne ke liye UPDATE use hota hai.

SQL 
UPDATE students
SET age = 22
WHERE id = 1;
Important: UPDATE me WHERE lagana bahut important hai. WHERE miss hone par multiple/all rows update ho sakti hain.

17. DELETE

Specific rows delete karne ke liye DELETE use hota hai.

SQL 
DELETE FROM students
WHERE id = 4;
Warning: DELETE without WHERE table ki sabhi rows delete kar sakta hai.

18. NULL

NULL ka matlab generally value missing/unknown hai. NULL ko normal = comparison se check nahi karte.

SQL 
SELECT *
FROM students
WHERE course IS NULL;
SQL 
SELECT *
FROM students
WHERE course IS NOT NULL;

19. SQL Constraints

Constraints database me rules define karte hain, jisse invalid data insert hone se roka ja sake.

  • PRIMARY KEY: uniquely identifies a row.
  • FOREIGN KEY: tables ke beech relationship.
  • NOT NULL: value required.
  • UNIQUE: duplicate values prevent karta hai.
  • DEFAULT: default value set karta hai.
  • CHECK: condition enforce karta hai.
SQL 
CREATE TABLE employees (
  id INT PRIMARY KEY,
  email VARCHAR(100) UNIQUE,
  name VARCHAR(100) NOT NULL,
  salary DECIMAL(10,2) CHECK (salary >= 0),
  city VARCHAR(50) DEFAULT 'Delhi'
);

20. PRIMARY KEY

Primary key kisi table ke har row ko uniquely identify karta hai. Isme duplicate value nahi honi chahiye aur primary key NULL nahi hoti.

SQL 
CREATE TABLE students (
  id INT PRIMARY KEY,
  name VARCHAR(50)
);

21. FOREIGN KEY

Foreign key ek table ke column ko doosri table ke primary key se connect karti hai.

SQL 
CREATE TABLE courses (
  course_id INT PRIMARY KEY,
  course_name VARCHAR(50)
);

CREATE TABLE students (
  id INT PRIMARY KEY,
  name VARCHAR(50),
  course_id INT,
  FOREIGN KEY (course_id)
    REFERENCES courses(course_id)
);

22. ALTER TABLE

Existing table ki structure change karne ke liye ALTER TABLE use hota hai.

Add column

SQL 
ALTER TABLE students
ADD email VARCHAR(100);

Drop column

SQL 
ALTER TABLE students
DROP COLUMN email;

Rename column

SQL 
ALTER TABLE students
RENAME COLUMN name TO full_name;

23. DELETE vs TRUNCATE vs DROP

Ye teen commands alag situations me use hoti hain.

  • DELETE: rows remove karta hai; WHERE ke saath selected rows delete kar sakte hain.
  • TRUNCATE: table ki all rows remove karta hai, table structure rehti hai.
  • DROP: table/database ka structure bhi remove karta hai.
SQL 
DELETE FROM students WHERE id = 2;

TRUNCATE TABLE students;

DROP TABLE students;

24. SQL Aggregate Functions

Aggregate functions multiple rows ke data se ek result calculate karti hain.

  • COUNT() — number of rows
  • SUM() — total
  • AVG() — average
  • MIN() — minimum
  • MAX() — maximum
SQL 
SELECT
  COUNT(*) AS total_students,
  AVG(age) AS average_age,
  MIN(age) AS youngest,
  MAX(age) AS oldest
FROM students;

25. GROUP BY

Same values ko group karke aggregate calculation karne ke liye GROUP BY use hota hai.

SQL 
SELECT course, COUNT(*) AS total
FROM students
GROUP BY course;

26. HAVING

HAVING grouped results ko filter karta hai. Ye commonly GROUP BY ke saath use hota hai.

SQL 
SELECT course, COUNT(*) AS total
FROM students
GROUP BY course
HAVING COUNT(*) >= 2;
Easy rule: WHERE individual rows ko filter karta hai, HAVING groups ko filter karta hai.

27. LIKE Operator

Pattern matching ke liye LIKE use hota hai.

  • % = zero or more characters
  • _ = exactly one character
SQL 
-- Names starting with A
SELECT *
FROM students
WHERE name LIKE 'A%';

-- Names ending with n
SELECT *
FROM students
WHERE name LIKE '%n';

28. IN and BETWEEN

Multiple possible values check karne ke liye IN aur range check karne ke liye BETWEEN use hota hai.

SQL 
SELECT *
FROM students
WHERE course IN ('CSE', 'ECE');

SELECT *
FROM students
WHERE age BETWEEN 20 AND 25;

29. SQL JOINs

JOIN ka use related tables se data combine karne ke liye hota hai.

INNER JOIN

Sirf matching records return karta hai.

SQL 
SELECT s.name, c.course_name
FROM students s
INNER JOIN courses c
ON s.course_id = c.course_id;

LEFT JOIN

Left table ke all records aur matching right records return karta hai.

SQL 
SELECT s.name, c.course_name
FROM students s
LEFT JOIN courses c
ON s.course_id = c.course_id;

RIGHT JOIN

Right table ke all records aur matching left records return karta hai.

SQL 
SELECT s.name, c.course_name
FROM students s
RIGHT JOIN courses c
ON s.course_id = c.course_id;

30. SELF JOIN

Jab table ko khud ke saath join karte hain, use SELF JOIN kaha jata hai. Employee-manager relationships me useful hai.

SQL 
SELECT
  e.name AS employee,
  m.name AS manager
FROM employees e
LEFT JOIN employees m
ON e.manager_id = m.id;

31. Subquery

Ek SQL query ke andar another SQL query ko subquery kehte hain.

SQL 
SELECT name, salary
FROM employees
WHERE salary > (
  SELECT AVG(salary)
  FROM employees
);

Is example me average salary se zyada salary wale employees milenge.

32. CTE — Common Table Expression

CTE complex query ko readable aur manageable banane ke liye temporary named result set provide karta hai.

SQL 
WITH high_salary AS (
  SELECT *
  FROM employees
  WHERE salary > 50000
)
SELECT name, salary
FROM high_salary;

33. CASE Expression

SQL me conditional output generate karne ke liye CASE use hota hai.

SQL 
SELECT
  name,
  salary,
  CASE
    WHEN salary >= 80000 THEN 'High'
    WHEN salary >= 50000 THEN 'Medium'
    ELSE 'Low'
  END AS salary_level
FROM employees;

34. String Functions

Text data par operations perform karne ke liye string functions use hoti hain.

  • UPPER()
  • LOWER()
  • CONCAT()
  • LENGTH()
  • TRIM()
  • SUBSTRING()
SQL 
SELECT
  UPPER(name) AS upper_name,
  LOWER(name) AS lower_name,
  LENGTH(name) AS name_length
FROM students;

35. Date and Time Functions

MySQL me date/time ke liye built-in functions available hain.

SQL 
SELECT CURDATE();

SELECT NOW();

SELECT YEAR(joining_date)
FROM employees;

36. VIEW

View ek virtual table hoti hai jo ek SQL query ke result par based hoti hai. Isme generally original data ki separate copy store nahi hoti.

SQL 
CREATE VIEW cse_students AS
SELECT id, name, age
FROM students
WHERE course = 'CSE';

SELECT *
FROM cse_students;

37. INDEX

Index database ko particular columns par records faster find karne me help karta hai. Lekin unnecessary indexes writes ko slower aur storage usage ko higher kar sakte hain.

SQL 
CREATE INDEX idx_student_name
ON students(name);

Index check karna

SQL 
SHOW INDEX FROM students;

38. Normalization

Normalization database design technique hai jiska goal unnecessary data duplication aur update anomalies ko reduce karna hai.

1NF

Har field me atomic/single value honi chahiye.

2NF

Table 1NF me ho aur non-key attributes complete primary key par depend karein.

3NF

Table 2NF me ho aur non-key attributes kisi other non-key attribute par depend na karein.

Simple idea: Data ko logically separate tables me organize karo taaki repeated information kam ho aur consistency improve ho.

39. Transactions

Transaction SQL operations ka logical group hota hai. Banking transfer iska common example hai.

SQL 
START TRANSACTION;

UPDATE accounts
SET balance = balance - 1000
WHERE id = 1;

UPDATE accounts
SET balance = balance + 1000
WHERE id = 2;

COMMIT;

40. COMMIT and ROLLBACK

COMMIT transaction ke changes ko permanently save karta hai. ROLLBACK transaction ke uncommitted changes ko undo kar sakta hai.

SQL 
START TRANSACTION;

UPDATE students
SET age = 25
WHERE id = 1;

ROLLBACK;

41. SAVEPOINT

Transaction ke beech ek checkpoint banane ke liye SAVEPOINT use hota hai.

SQL 
START TRANSACTION;

UPDATE students
SET age = 22
WHERE id = 1;

SAVEPOINT point1;

UPDATE students
SET age = 23
WHERE id = 2;

ROLLBACK TO point1;

COMMIT;

42. ACID Properties

Reliable database transactions ke four important properties ko ACID kehte hain.

  • Atomicity: transaction all-or-nothing principle follow karta hai.
  • Consistency: transaction database ko valid state me rakhta hai.
  • Isolation: concurrent transactions ek doosre ke intermediate state ko improperly affect na karein.
  • Durability: committed changes failure ke baad bhi persist karne ke liye database mechanisms use karta hai.

43. Stored Procedure

Stored procedure database server par stored SQL statements ka reusable program-like block hota hai.

SQL / MySQL 
DELIMITER //

CREATE PROCEDURE GetStudents()
BEGIN
  SELECT *
  FROM students;
END //

DELIMITER ;

CALL GetStudents();

44. Trigger

Trigger automatically execute hone wala database object hai jo INSERT, UPDATE ya DELETE jaise events ke response me run ho sakta hai.

SQL / MySQL 
CREATE TRIGGER before_student_insert
BEFORE INSERT ON students
FOR EACH ROW
SET NEW.name = TRIM(NEW.name);

45. UNION and UNION ALL

Multiple SELECT queries ke result ko combine karne ke liye UNION use hota hai.

  • UNION: duplicate rows remove karta hai.
  • UNION ALL: duplicates ko preserve karta hai.
SQL 
SELECT name FROM students
UNION
SELECT name FROM employees;

46. Window Functions

Window functions related rows ke group par calculation karti hain bina rows ko ek single row me collapse kiye.

ROW_NUMBER()

SQL 
SELECT
  name,
  salary,
  ROW_NUMBER() OVER (
    ORDER BY salary DESC
  ) AS salary_rank
FROM employees;

PARTITION BY

Partition data ko logical groups me divide karta hai.

SQL 
SELECT
  name,
  department,
  salary,
  RANK() OVER (
    PARTITION BY department
    ORDER BY salary DESC
  ) AS dept_rank
FROM employees;

47. EXISTS

EXISTS check karta hai ki subquery kam se kam ek matching row return karti hai ya nahi.

SQL 
SELECT s.name
FROM students s
WHERE EXISTS (
  SELECT 1
  FROM courses c
  WHERE c.course_id = s.course_id
);

48. SQL Query Execution Order

Query likhne ka order aur database ke logical processing order me difference ho sakta hai.

Common logical order:
FROM → JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT

Ye concept complex queries aur interview questions samajhne me bahut useful hai.

49. SQL Performance Basics

Large database me query performance important hoti hai.

  • Only required columns select karo instead of unnecessary *.
  • Frequently searched columns par suitable indexes consider karo.
  • Joins ke columns ko carefully index karo.
  • Large datasets par pagination use karo.
  • Query execution plan samajhne ke liye EXPLAIN use karo.
SQL / MySQL 
EXPLAIN
SELECT *
FROM students
WHERE course = 'CSE';

50. Mini Practical Example — Student Database

Ab basic se advanced concepts ko ek small practical example me connect karte hain.

Step 1 — Database

SQL 
CREATE DATABASE college;
USE college;

Step 2 — Courses table

SQL 
CREATE TABLE courses (
  course_id INT PRIMARY KEY,
  course_name VARCHAR(50) NOT NULL
);

Step 3 — Students table

SQL 
CREATE TABLE students (
  id INT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  age INT,
  course_id INT,
  FOREIGN KEY (course_id)
    REFERENCES courses(course_id)
);

Step 4 — Insert data

SQL 
INSERT INTO courses
(course_id, course_name)
VALUES
(1, 'CSE'),
(2, 'ECE');

INSERT INTO students
(id, name, age, course_id)
VALUES
(101, 'Ankit', 21, 1),
(102, 'Rahul', 22, 1),
(103, 'Amit', 20, 2);

Step 5 — Join and display

SQL 
SELECT
  s.id,
  s.name,
  s.age,
  c.course_name
FROM students s
JOIN courses c
ON s.course_id = c.course_id
ORDER BY s.name;
