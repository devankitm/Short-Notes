MongoDB Short Notes

Short MongoDB notes covering documents, collections, CRUD operations and common queries.

1. What is MongoDB?

MongoDB is a NoSQL document database. Data is stored as flexible JSON-like documents inside collections.

2. Select a Database

use switches to a database. MongoDB creates it when data is first stored.

MongoDB Shell
use college

3. Insert Document

Use insertOne() to add a single document.

MongoDB Shell
db.students.insertOne({
  name: "Ankit",
  age: 21,
  course: "CSE"
});

4. Find Documents

find() reads documents. Add a filter object to match specific records.

MongoDB Shell
db.students.find({ age: { $gte: 18 } });

5. Update Document

updateOne() changes a matching document.

MongoDB Shell
db.students.updateOne(
  { name: "Ankit" },
  { $set: { age: 22 } }
);

6. Delete Document

deleteOne() removes the first matching document.

MongoDB Shell
db.students.deleteOne({
  name: "Ankit"
});

7. Aggregation

Aggregation processes documents through stages such as $match, $group and $sort.

MongoDB Shell
db.students.aggregate([
  { $match: { age: { $gte: 18 } } },
  { $group: { _id: "$course", total: { $sum: 1 } } }
]);
