DATA STRUCTURES & ALGORITHMS

DSA Short Notes

Quick DSA revision with complexity, arrays, searching, sorting, stacks and queues.

1. What is DSA?

Data Structures organize data, while Algorithms define steps to solve a problem efficiently.

Goal: solve correctly while keeping time and space usage reasonable.

2. Time Complexity

Big-O describes how running time grows as input size increases.

JavaScript
// O(1)
const first = arr[0];

// O(n)
for (const item of arr) {
  console.log(item);
}

3. Array

An array stores values in an ordered collection and provides index-based access.

JavaScript
const numbers = [10, 20, 30];

console.log(numbers[0]); // 10
numbers.push(40);

4. Linear Search

Linear search checks elements one by one. Its worst-case time complexity is O(n).

JavaScript
function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) return i;
  }
  return -1;
}

5. Binary Search

Binary search repeatedly halves a sorted array. Time complexity is O(log n).

JavaScript
function binarySearch(arr, target) {
  let left = 0;
  let right = arr.length - 1;

  while (left <= right) {
    const mid = Math.floor((left + right) / 2);

    if (arr[mid] === target) return mid;
    if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }

  return -1;
}

6. Stack

Stack follows LIFO: Last In, First Out. Common operations are push and pop.

JavaScript
const stack = [];

stack.push(10);
stack.push(20);

console.log(stack.pop()); // 20

7. Queue

Queue follows FIFO: First In, First Out.

JavaScript
const queue = [];

queue.push("A");
queue.push("B");

console.log(queue.shift()); // A
