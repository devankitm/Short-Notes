Java Short Notes

Core Java revision notes with classes, objects, inheritance, exceptions and collections.

1. Java Basics

Java is a class-based, object-oriented language designed to run on the JVM.

Java
public class Main {
  public static void main(String[] args) {
    System.out.println("Hello Java");
  }
}

2. Class and Object

A class is a blueprint. An object is an instance of a class.

Java
class Student {
  String name;

  Student(String name) {
    this.name = name;
  }
}

Student s = new Student("Ankit");

3. Inheritance

Inheritance allows a child class to reuse members of a parent class.

Java
class Animal {
  void sound() {
    System.out.println("Sound");
  }
}

class Dog extends Animal {
  void bark() {
    System.out.println("Bark");
  }
}

4. Exception Handling

Use try-catch to handle exceptions without abruptly stopping normal program flow.

Java
try {
  int result = 10 / 0;
} catch (ArithmeticException e) {
  System.out.println("Cannot divide by zero");
}

5. ArrayList

ArrayList is a resizable list from the Java Collections Framework.

Java
import java.util.ArrayList;

ArrayList names = new ArrayList<>();
names.add("Ankit");
names.add("Rahul");

System.out.println(names);
