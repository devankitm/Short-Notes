JavaScript Short Notes

Practical JavaScript notes from fundamentals to modern asynchronous programming.

1. Variables

Use const for values that will not be reassigned and let for values that can change.

JavaScript
const name = "Ankit";
let age = 21;

age = 22;
console.log(name, age);

2. Functions

Functions group reusable logic.

JavaScript
function add(a, b) {
  return a + b;
}

console.log(add(10, 20));

3. Array Methods

Methods such as map, filter and reduce are useful for transforming data.

JavaScript
const nums = [1, 2, 3, 4];

const squares = nums.map(n => n * n);
const even = nums.filter(n => n % 2 === 0);

4. DOM

The DOM lets JavaScript read and update HTML elements.

JavaScript
const heading = document.querySelector("h1");

heading.textContent = "Hello JavaScript";

5. Async / Await

async functions can use await to work with promises in a readable way.

JavaScript
async function getUsers() {
  const response = await fetch("/api/users");
  const users = await response.json();
  console.log(users);
}

getUsers();

6. Event Listener

Use addEventListener to respond to user actions.

JavaScript
const button = document.querySelector("#save");

button.addEventListener("click", () => {
  console.log("Saved");
});
