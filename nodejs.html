Node.js Short Notes

Node.js fundamentals for server-side JavaScript, modules, HTTP and Express APIs.

1. What is Node.js?

Node.js is a JavaScript runtime built on the V8 engine. It allows JavaScript to run outside the browser.

2. Module

Modules help split backend code into reusable files.

JavaScript
const path = require("path");

console.log(path.join("src", "app.js"));

3. HTTP Server

The built-in HTTP module can create a basic web server.

JavaScript
const http = require("http");

const server = http.createServer((req, res) => {
  res.end("Hello Server");
});

server.listen(3000);

4. Express Route

Express makes routing and API development simpler.

JavaScript
const express = require("express");

const app = express();

app.get("/api/users", (req, res) => {
  res.json({ message: "Users API" });
});

app.listen(3000);

5. Middleware

Middleware runs between the request and the final route handler.

JavaScript
app.use((req, res, next) => {
  console.log(req.method, req.url);
  next();
});
