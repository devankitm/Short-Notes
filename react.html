React Short Notes

React notes for components, JSX, props, state and common hooks.

1. What is React?

React is a JavaScript library for building user interfaces with reusable components.

2. Component

A component is a reusable UI unit. Function components are the common modern approach.

JSX
function Welcome() {
  return 
Hello React
;
}

export default Welcome;

3. Props

Props pass data from a parent component to a child component.

JSX
function User({ name }) {
  return 
Hello {name}
;
}

4. useState

useState stores local component state.

JSX
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  );
}

5. useEffect

useEffect runs side effects such as data fetching or subscriptions.

JSX
import { useEffect } from "react";

useEffect(() => {
  console.log("Component mounted");
}, []);
